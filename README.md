## 🛠 Methodology
1. **Stationarity**: Fisher-type ADF tests on log-differenced variables.
2. **Lag Selection**: Optimal lags chosen based on AIC/SBIC (typically 4 lags).
3. **Identification**: Structural VAR using A and B matrix restrictions (Cholesky-type identification).
