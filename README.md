# Structural Shock Synchronisation and Integration in Northeast Asia

Structural VAR (SVAR) analysis of macroeconomic shock synchronisation in East Asian economies.

This repository contains the replication materials for a study on whether trade and financial integration increase structural shock synchronisation in Northeast/East Asia. The analysis covers South Korea, China, Japan, Taiwan, and Hong Kong, using quarterly macroeconomic data and pair-level integration indicators.

## 📌 Project Overview

The project proceeds in three stages.

1. **SVAR estimation**  
   Country-specific SVAR models are estimated using output growth, inflation, and REER changes. Global financial controls, including the US Fed Funds Rate and VIX, are included as exogenous variables.

2. **Shock synchronisation analysis**  
   SVAR-identified structural shocks are extracted and used to calculate bilateral shock correlations. Both static correlations and rolling correlations are constructed.

3. **Panel regression analysis**  
   Rolling shock correlations are regressed on trade integration, financial integration, and industrial structural difference using country-pair fixed effects, time fixed effects, and Driscoll-Kraay standard errors.

  Robustness dataset using 12-quarter rolling correlations and 12-quarter moving-average regressors.

## 🛠 Methodology

The empirical strategy consists of four main components.

1. Stationarity
Log-transformed macroeconomic variables are first-differenced. Fisher-type ADF tests are used to assess stationarity.
2. SVAR identification
The SVAR is identified using a recursive Cholesky-type ordering: output growth → inflation → REER change
3. Shock synchronisation
Structural shocks are extracted from the SVAR models. Bilateral shock synchronisation is measured using 20-quarter rolling correlations. A 12-quarter rolling window is used as a robustness check.
4. Panel regression
Pair-level shock synchronisation is regressed on trade integration, financial integration, and industrial structural difference. The preferred specification includes country-pair fixed effects, time fixed effects, and Driscoll-Kraay standard errors.

## Robustness Checks
The following robustness checks are implemented.

1. Specification without time fixed effects
2. 12-quarter rolling/moving window
3. Nominal interest rate convergence as an alternative financial integration measure
4. Excluding the COVID period
5. Four-quarter lagged regressors
6. Excluding Hong Kong pairs

## Notes
The preferred regression specification uses country-pair fixed effects and time fixed effects.
Driscoll-Kraay standard errors are used to account for heteroskedasticity, serial correlation, and cross-sectional dependence.
The baseline analysis uses 20-quarter rolling correlations and 20-quarter moving averages.
The 12-quarter specification is used as a robustness check.
